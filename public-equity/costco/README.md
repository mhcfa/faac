# Costco Wholesale Corp. (`COST`) — Financial Model & Valuation

Financial model built with [`f8-engine`](https://github.com/mhcfa/f8) autonomously by AI agents.

## Deliverables

- `deliverables/costco-equity-valuation.pdf`
- `deliverables/costco-valuation.xlsx`

## Usage

```bash
# Run model verification & accounting identity test suite
pnpm test

# Typecheck model schedules
pnpm typecheck

# Compile and emit the multi-sheet Excel workbook (.xlsx)
pnpm build
```
